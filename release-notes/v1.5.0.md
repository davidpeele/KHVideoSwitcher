## Redesigned interface

The app has a new light-themed look with a persistent status rail (Virtual Camera, Auto Scenes, Auto-Take, Drag Mode, Set Stock) so those states are always visible, no matter which button triggers them. Scene tiles now show a filled/hollow dot for the active scene, and presets display their saved scene at a glance.

The zoom control now sits in its own row directly below the PREVIEW pane instead of overlapping the video, so it's easier to see and grab.

Settings now shows live value readouts on the sliders and a preview box for the over-the-shoulder inset position/size.

## Other changes

- Added a GitHub Actions CI/release pipeline so releases are now built and published from a clean, trusted environment (paving the way for SignPath code signing once that application is approved).
